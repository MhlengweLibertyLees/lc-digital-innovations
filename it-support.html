IT support for small businesses, charities and households

What we do

  • New device setup: setting up a new PC or laptop for daily use
  • System build: installing Windows, drivers and standard programs
  • Software installation with valid licences only
  • Windows and program updates on a schedule
  • Operating system upgrade: moving an older computer to a supported newer version of Windows (for example Windows 10 to Windows 11), where the hardware and licence allow it. Your files are backed up first.
  • Clean reinstall of a supported version of Windows, with your files backed up first and restored after. We do not install unsupported or older versions that no longer receive security updates.
  • Blue screen of death (BSOD) troubleshooting: checking recent updates and drivers, testing memory and disk health, reading crash reports and restoring from backup where needed. If the fault is hardware, we tell you what is wrong and quote for the repair. We do not promise to fix every hardware fault.
  • Basic antivirus installation and updates
  • Data backup before a reinstall: we copy your files to an external drive or cloud storage and check that the copied files open. We do not promise recovery from a physically damaged drive.
  • Hardware upgrades: replacing faulty memory (RAM) or storage (hard drive or SSD)
  • Laptop optimisation: speeding up slow laptops
  • Laptop diagnosis: finding the fault before any repair and telling you what it is
  • Boot storage recovery: fixing a disconnected or failed boot drive problem
  • Connectivity fixes: Wi-Fi and network problems
  • Helpdesk: logging, tracking and closing support requests
  • Remote support, with your permission, or on-site support at your premises

What you receive

A ticket history, a support log and a handover guide.

What we need from you

A short description of the problem and the make and model of the device.

Who it suits

Small businesses, charities and households with computers that are slow, broken or need setting up.
